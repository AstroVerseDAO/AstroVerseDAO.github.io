科技

火 · 工具与创造

为什么学：科技是五大航向中唯一以工程为核心的方向，但它不是「程序员速成班」。目标是三件事：理解世界如何运转——从晶体管的物理到神经网络的学习；掌握创造的双手——不只是会用工具，而是能造出工具；为 AI 时代做好准备——通用型 AI 人才 = 扎实的数学与系统功底 + 完整的 EE 硬件视野 + 前沿的 AI 能力。

L0工具与数学 →L1编程入门 →L2EE 与体系结构 →L3计算机核心 →L4系统深入 →L5AI 与安全

必做项目 · 每个 Level 一件真东西

做一个真实的东西，胜过听十节课

  • L0　用 LaTeX 写一份数学笔记；用命令行脚本自动化一件日常琐事
  • L1　完成 CS61A 或 CS50 的全部 Project，并放进自己的 GitHub
  • L2　用电路知识做一台能「感知世界」的小装置（传感器 → 信号 → 反馈控制）
  • L3　实现一个迷你操作系统（xv6 扩展）/ 迷你 TCP 协议栈 / 迷你数据库（任选其一）
  • L4　从零训练并部署一个小模型（微调一个 LLM 或实现 Needle 类自动微分库）
  • L5　打一次 CTF，或完成 SEED Labs 全部实验
学习顺序建议
  1. 不要跳过 L0。 数学是 AI 的地基，EE 是 AI 的翅膀，都建立在数学之上。
  2. L2 与 L3 可以并行。 EE 核心（信号、控制）与 CS 核心（系统、网络）是两条互补的主干。
  3. 每学一个理论，配一个实践。 学了信号与系统就写个音频滤波器，学了控制论就做一个自平衡小车。
  4. 用输出倒逼输入。 笔记、项目、复盘都发到 GitHub——你会学得更快。
