课程简介

8 个 Checkpoint 用 C++ 搭出整个 TCP/IP 协议栈，也是最好的现代 C++ 实践课。

斯坦福的新版网络课：从字节流、TCP 收发器、IP 路由一路写到网络接口，最终组成一个能与真实互联网通信的协议栈。Lab 用现代 C++ 编写，测试框架完善。学完后 TCP 的三次握手对你不再是背诵题。
