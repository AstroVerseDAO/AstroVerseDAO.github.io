壹 · 宣言

读完一门课程，

并不等于准备好进入这个世界。

投资与复利、如何与人打交道、历史中的经验、身体与生存——这些真正决定人生走向的东西，在大学里反而最缺失。星宙要补上的，正是这一课。

学习机制借鉴 School 42（无教师、项目驱动、同伴互评）与 Astra Nova（跨学科、面向真实世界问题）两所先锋学校。

贰 · 五大航向

不是五门互不相干的课，
而是观察同一个世界的五片星空。

Ⅰ 政治 权力与秩序 制度、权力与秩序如何塑造社会。看懂规则，才能参与游戏，而不只是被规则塑造。 政治学导论 → 制度与博弈 → 国际关系 → 现代治理 → Ⅱ 经济 金钱与时间 学习投资与复利，理解市场与资源配置，让时间成为你的盟友。 经济学原理 → 会计与财务 → 投资与复利 → 行为与决策 → Ⅲ 科技 工具与创造 编程、AI、网络安全与硬件。掌握工具，更要拥有创造工具的能力。 数学 → 编程 → EE 与体系结构 → 计算机核心 → AI 与安全 → Ⅳ 历史 记忆与智慧 前人用血泪总结的经验，是我们最便宜的学费。读史，是为了不重复犯错。 世界通史 → 中国历史 → 思想史 → 技术史 → Ⅴ 宇宙 星海与未知 科学世界观：我们从哪里来，宇宙如何运行。保持谦卑，保持好奇。 天文学 → 物理学 → 科学方法论 → 演化论 →

叁 · 修习机制

五个阶段，一条轨道。

  1. Piscine · 启航周

    30 天零门槛高强度挑战。先把自己扔进水里，学会「学习如何学习」。

  2. 五大航向 · 核心路径

    每方向一条从零开始的完整路径：理论 → 实践 → 必做项目。

  3. Conundrums · 谜题环

    每阶段一个跨学科开放题：伦理 × AI × 经济 × 生存。没有标准答案，只有更好的论证。

  4. Expedition · 远征项目

    开源项目 / 虚拟公司 / 投资实盘 / 野外生存——把知识做成真实世界的作品。

  5. Capstone · 毕业课题

    自主选题，公开答辩。它授予的不是文凭，而是完整的自学能力。
